AI 服务（用于高质量翻译 + 课堂概要）

不填也能用：Chrome 内置的本地翻译／摘要会顶上，再不行会用内置的离线摘要。填了 Key 质量最好。Key 只保存在你这台电脑的浏览器里，不会上传到任何第三方。

翻译

课后精修

精修 = 用更准的 whisper-small 重新识别整段录音 → 重新翻译 → 把新译文和上课时的旧译文逐句对比打分取优（重新识别之后原文都可能不一样， 所以这是真的两个候选）。评分是确定性规则：数字和日期保真权重最高（作业时间错了最要命）， 其次是术语正确性和内容覆盖度。落选的那版会保留，可以随时切换查看。

省电

打开后：翻译从 8 秒一批改成 20 秒一批、音量表从 8fps 降到 2fps、不阻止屏幕休眠。
桌面 App 里开这个不掉准确率 —— 识别本来就全靠本地 Whisper，省电模式不会关掉它， 只是把界面刷新和翻译放慢。没插电、课又长的时候放心开。
（在浏览器里打开这个页面时才有区别：那时省电会停掉本地 Whisper 只留浏览器识别，远距离准确率会降。）

本地小 AI（可选）

实测结论（2026-09-21）：不建议开。 1.5B 在浏览器里 WebGPU 会数值崩溃输出乱码、 CPU 又内存不足；0.5B 能跑但会编造内容——把「数字时代隐私观念的变化」译成 「这是个好问题但需要时间回答」，把「下周五午夜前」译成「明天凌晨四点」。 三条测试全部被择优器拦下，0 胜 3 负。同样的模型在命令行环境里是正常的，是浏览器端的后端问题。
不需要 API Key、不联网，但第一次要下载 500MB~1.2GB，而且生成一份笔记要一两分钟。 它只负责把已经抽取出来的定义、考点、作业改写成通顺中文，不允许它编造素材里没有的内容， 写飞了会自动退回原来的抽取式笔记。
想要真正高质量的笔记，更推荐用课程页里的「🤖 打包给 AI 学习」，把内容贴进 Claude / ChatGPT 的免费网页版。

远距离 / 大教室

大教室的正确用法：开启远距离模式（它会自动换成更准的 whisper-small，并对音频做大厅增强）。
上课时离得远、字幕有错是正常的。下课后到那节课里点 「🖥 用录音重新识别整节课（本地，免费）」 —— 用整段录音重跑一遍，比边录边出的准得多， 不用联网、不用 API Key、不花钱。旁边的「☁︎ 用云端重新转写」是可选的，需要自己配 Key，不配也完全够用。
分段音频大约每小时多占 25–30 MB，转写完可以在下面删掉。

云盘自动备份

课程仍然存在本机（快、能搜、离线可用），但每节课结束后会自动写一份完整备份 到你选的云盘文件夹里——讲稿、翻译、笔记、原始录音全在一个文件里。 电脑坏了或换设备，在新机器上「导入课程包」就全回来了。
不需要注册账号、不需要 API Key，用的是你电脑上已有的 iCloud / Google Drive。
