# 大教室远距离录音指南

> 场景：阶梯大教室，老师戴着话筒、走 PA 扩音，你坐在离讲台四五十米的后排。
> 目标：录下来能听清，识别出来的讲稿能用。

先说结论：**这件事做得成，但不能靠"打开网页按录制"就完事。** 下面按"为什么—坐哪—买什么—软件怎么设—上课前检查—出问题怎么查"的顺序讲。

---

## 一、先搞明白物理现实（别被"50 米"吓到）

很多人一听"50 米"就觉得没戏。其实**有 PA 扩音的时候，距离不是主要矛盾**。

**1）你并不是离声源 50 米。**
老师的嘴离你 50 米，但 PA 音箱不是。阶梯教室的扩音系统本来就是为了让最后一排也听清而设计的——要么是讲台两侧的大音箱对着全场打，要么是天花板上一排排吸顶喇叭（分布式布置）。也就是说，**离你最近的那个喇叭，可能只有三五米远**。你要录的是它，不是老师本人。想清楚这一点，后面的座位选择就全通了。

**2）音量通常够用。**
正常运行的教室 PA，会把听众位置的语音声压做到大概 70 dB SPL 上下（比日常对话稍大一点，全场基本均匀）。笔记本内置麦克风在这个音量下是**完全能拾到**的——录音波形不会是一条直线。

**3）真正的敌人是三个，都不是"远"：**

| 敌人 | 它干了什么 | 后果 |
|---|---|---|
| **混响** | 大教室空间大、硬墙硬地，声音在墙之间来回反射，尾巴拖 1 秒以上 | 每个字的尾音糊在下个字头上，辅音（t/p/k/s）被抹平 |
| **人群噪声** | 翻书、咳嗽、椅子、周围小声讲话、键盘 | 你旁边的键盘声，在麦克风听来比 50 米外的老师"近得多" |
| **空调 / 投影仪风扇** | 持续的低频轰鸣 | 抬高底噪，压低信噪比，AI 会把它当成"有人在说话"而乱插词 |

所以专业上有个说法叫"临界距离"——超过它之后，麦克风收到的反射声就比直达声还多了。大教室里这个距离往往只有几米。**你在后排，无论如何都在混响区里**，指望靠麦克风"够得着讲台"是错方向；正确方向是**离最近的喇叭更近、让人群噪声更少**。

**4）这对识别引擎意味着什么（重要）：**

- **浏览器自带的实时识别**（Chrome 的 Web Speech API）是为"手机怼嘴边"调的，一进混响环境掉得非常厉害——可能只剩六七成准，或者干脆整句吞掉。
- **Whisper** 是在海量真实录音（包括讲座、会议、播客）上训过的，对混响和背景噪声的耐受度高一个量级。**大教室 = 必须用 Whisper。**
- 另外，macOS 桌面版（Electron 打包的那个）里根本没有浏览器实时识别可用——Chromium 不带 Google 的语音服务。**桌面版只有 Whisper 这一条路**，这反而省了你纠结。

## 二、座位和摆放：免费，但收益最大

这一节不花钱，效果往往超过你花两百块买麦克风。

**选座位**

- **优先挨着一个音箱坐**。进教室先抬头看：天花板上有没有一圈圆盘状的吸顶喇叭？侧墙上有没有挂着的箱子？挑一个正下方或斜下方的位置，距离三到五米最好。
- **别贴着墙角或最后一排靠墙**。墙角是混响最脏的地方，低频堆积。往中间挪两个座位就有明显差别。
- **避开空调出风口正下方**，也避开走道旁边（人来人往、开关门）。
- **离投影仪、离讲台风扇远一点**。
- 如果教室有阶梯分区，**中后区靠中线** 通常比"最后一排"好，而且往往还有空位。

**怎么摆电脑**

- 笔记本**打开、平放在桌面上**，屏幕正常角度。
- **找到麦克风孔在哪**（MacBook 一般在键盘上方一排小孔，或左侧扬声器格栅旁边），**千万别用手、纸、笔袋、外接硬盘压住它**。
- **让麦克风那一侧朝向音箱的方向**——把电脑稍微斜一点摆就行，不用夸张到影响打字。
- **不要放在腿上**（衣服摩擦声直接进麦）、**不要放在包里或半合着**、**不要塞在书堆中间**。
- **桌面尽量别放在你手边敲字的位置附近**：如果你要用同一台电脑记笔记，键盘声会被收进去。可以在电脑下面垫一本软皮本或一块布，能显著降低敲击的结构传声。
- **插电源**。录一节 90 分钟的课 + 本地转写很吃电，后面讲能耗的那节还会说。

## 三、硬件：按预算分档（带大致价格）

### 第 0 档：0 元 —— 内置麦 + 本应用的大教室模式

**先试这个，别急着买东西。** 用上面的座位和摆放建议 + 应用里的「大教室模式」，配合课后 Whisper 重新转写，**大部分有 PA 的教室能到八九成可用**。真的不行再升级。

### 第 1 档：￥100–300 / $15–45 —— USB 桌面指向性麦克风

性价比最高的一档。挑选要点：

| 看什么 | 要的 | 为什么 |
|---|---|---|
| 指向性 | **心形（Cardioid）** 或 超心形 | 正前方灵敏、后方抑制。正对着音箱方向摆 |
| 接口 | **USB 免驱（UAC 兼容）** | 插上 macOS 直接认，不用装驱动 |
| 供电 | USB 取电即可 | 别买需要 48V 幻象电源的 XLR 电容麦，那还得配声卡 |
| 形态 | 桌面小三脚架 / 可调角度 | 要能把头抬起来对着喇叭，而不是对着天花板 |
| 别买 | 会亮 RGB 的"电竞"款、号称"AI 降噪"的 | 花里胡哨的降噪算法常把远处人声一起削掉 |

常见能买到的品类关键词：**USB 电容麦 / 心形指向 / 桌面小话筒 / 会议麦克风**。二三百这一档，Fifine、Maono 这类都有，百元级的也能明显超过内置麦。

> 老实说一句：在 50 米 + 混响的环境里，一支 200 块的心形麦比内置麦的提升，大概是"能听清"到"听着舒服"，不是"从不能用到能用"。**真正决定成败的是 Whisper，不是麦克风。** 所以别为这个花大钱。

### 第 2 档：￥500–1500 / $70–200 —— 枪式麦克风 / 无线领夹

- **枪式麦克风（Shotgun）**：指向更尖，能压掉一些侧面的人群噪声。但要泼一盆冷水：**枪麦不能"拉近"混响**。你在混响区里，反射声从四面八方来，枪麦只能削掉一部分。它的收益比宣传的小得多，不建议为了上课专门买。
- **无线领夹麦（Lavalier）**：这个是**理论最优解**——直接别在老师衣领上，信噪比爆炸好。但现实是：**必须先征得老师同意才能别在老师身上**，而且大多数老师会觉得别扭、或者学校有规定不允许。除非你和老师关系很好、或者你有正式的学业便利安排（accommodation），否则**当它不存在**。别没打招呼就去夹。

### 第 3 档：0 元，但效果碾压前面所有档 —— 直接拿官方音频

**这一条请一定看完，它可能让你不用买任何东西。**

1. **教室有没有音频输出口？**
   讲台控制面板上有时会有一个 3.5mm 耳机孔 / LINE OUT（有些是为助听设备预留的）。如果有，用一根 **3.5mm 公对公音频线**（十几块钱）接到笔记本输入口（MacBook 的耳机孔支持带麦的 TRRS，可能需要一个几十块的转接器）。这样拿到的是**直接从调音台出来的干净信号，没有任何混响**，识别率直接拉满。
   注意：用之前**问一下老师或教室技术人员**，别自己乱插——有些面板一插会把全场扩音切掉，很尴尬。

2. **学校有没有辅助收听设备（Assistive Listening）？**
   很多大教室按无障碍法规配了 FM / 红外 / 感应线圈系统，接收机在无障碍服务中心（Disability Services）免费借。接收机有耳机孔，接到电脑上和上面一样干净。

3. **学校有没有官方录播？**
   **Echo360 / Panopto / Canvas 里的 Lecture Capture / Zoom 录制 / Kaltura**——先去课程页面翻一翻。如果有，**这才是最优解**：直接下载官方录音文件，导入本应用用 Whisper 转写，音质是讲台麦克风直录的，比你在后排录的强太多。你现场录的那份就当个备份。

> 顺序建议：**官方录播 > 音频输出口 / 辅助收听设备 > 自己录**。花五分钟问一下教务或看一眼课程页面，可能省掉你整个学期的折腾。

## 四、本应用怎么设（大教室专用配置）

### 上课前设一次，以后不用动

1. **打开「大教室模式」**（设置里也可能写作「远距离模式」）
   打开后会自动做三件事：拉高软件增益、对录音做远场增强、强制保存分段音频。
   - **自动增益（AGC）**：开。远处声源全靠它把电平抬起来。
   - **降噪（NS）**：**默认别开**。系统降噪是为"一个人对着电脑说话"设计的，在大教室里它会把远处的老师一起当成噪声削掉，经常越降越糟。只有当空调声大到压住人声时，才试着开一下，并对比两节课的效果。
   - **软件增益**：大教室模式会自动给到 2× 以上。如果回放发现爆音破音，手动往回调一点；如果波形一直很小，再往上加。

2. **识别引擎选 Whisper**
   - 桌面版（macOS App）：只有 Whisper，不用选。
   - 网页版：浏览器实时识别可以留着当"现场能看见字"的即时反馈，但**真正的讲稿以 Whisper 为准**。

3. **模型选哪个**

| 模型 | 大小 | 适合 | 说明 |
|---|---|---|---|
| tiny | 最小 | 不建议 | 混响环境下错得离谱 |
| **base** | 小 | **上课时的实时/准实时** | 省电、快，用来现场看个大概 |
| **small** | 中 | **课后重新转写（推荐）** | 大教室场景的性价比甜点，准确度明显高于 base |
| medium / large | 大 | 电脑强 + 不赶时间 | 准确度最高，但慢、发热、耗电 |

**推荐组合：上课时用 base（或干脆不实时转写，只录音），下课后用 small 整段重新转写。**

4. **云端转写开不开？**
   - **开**（需要 OpenAI 兼容服务商的 Key）：准确率最高、最省电（算力在人家服务器上），代价是**课堂录音会上传**，以及少量费用。
   - **不开**：全部本地跑，隐私完全不出这台电脑，代价是慢一点、费电一点。
   - 如果课程内容敏感（涉及未发表研究、临床病例等），**用本地**。

5. **保存分段音频：一定要开**
   大教室模式会自动帮你开。它把录音切成一段一段存下来，**课后"整段重新转写"全靠它**。
   占用参考：**大约每小时 25–30 MB**。转写完确认没问题，可以在课程里把分段音频删掉。

### 下课后的关键一步（别忘了）

进那节课的详情页，点 **「☁︎ 用云端重新转写整节课」**（本地 Whisper 同理），模型选 **small**，模式选「替换」。

为什么这一步这么重要：**上课时是一边录一边猜，Whisper 只能看到 30 秒的碎片；课后是拿着完整音频重新来一遍，能利用上下文，准确率完全不是一个级别。** 大教室场景下，这一步的提升通常比你买任何麦克风都大。

转写要跑几分钟（90 分钟的课，用 small 在 Apple Silicon 上大概几分钟到十几分钟）。**建议插着电、合盖前先等它跑完**，或者干脆吃完饭回来再看。

### 顺手降能耗

- **上课时不开实时 Whisper**，只录音 + 记笔记，课后统一转写——这是最省电的用法。
- **实时翻译关掉**，课后再批量翻。
- 屏幕亮度调低、关掉其他标签页（尤其视频网站）。
- 本地转写时**插电**；用电池跑大模型会明显掉电且发烫。
- 长时间课程优先用 **base 实时 / small 课后**，不要全程 medium。

## 五、上课前 60 秒检查清单

- [ ] 电脑**插上电源**（或电量 > 60%）
- [ ] 座位挨着一个**音箱**，**避开**空调出风口和走道
- [ ] 笔记本平放桌面，**麦克风孔没被挡住**，那一侧朝向音箱
- [ ] 系统设置 → 声音 → 输入：**选对了麦克风**（用外接麦时尤其要确认，浏览器实时识别只认系统默认输入）
- [ ] 应用里**「大教室模式」已开**、**保存分段音频已开**
- [ ] 点一下**「麦克风试音」**，看音量条：老师开口讲话时条子要明显跳动
- [ ] 识别引擎 = **Whisper**，模型选好了
- [ ] 硬盘还有 **1 GB 以上**空间
- [ ] **静音通知**（勿扰模式），关掉会弹窗的 App
- [ ] 按下**开始录制**，确认计时器在走、第一句话出来了

## 六、故障排查表

| 现象 | 大概率原因 | 怎么办 |
|---|---|---|
| 音量条完全不动 | 系统输入设备选错了 / 浏览器没给麦克风权限 | 系统设置 → 声音 → 输入，选对设备；地址栏左边的图标里把麦克风设为"允许"；桌面版去 系统设置 → 隐私与安全性 → 麦克风 勾上本应用 |
| 音量条在动，但识别一片空白 | 用的是浏览器实时识别，它在混响里扛不住 | 换 Whisper；课后一定做「整段重新转写」 |
| 识别出来断断续续、只有零碎几个词 | 增益不够，远处人声被当成静音跳过 | 打开大教室模式、把软件增益往上加；**关掉降噪**；换个离音箱更近的座位 |
| 全是噪声乱码 / 凭空冒出奇怪句子 | 空调等底噪太大，模型在"幻听" | 换座位远离出风口；试着开一次降噪对比；用 small 以上的模型（小模型更容易乱编） |
| 录音有节奏性"哒哒哒" | 你自己在这台电脑上打字 | 电脑下面垫软垫；笔记写在别的设备/纸上；把电脑往外推一点 |
| 声音忽大忽小、像被掐着脖子 | 自动增益 + 软件增益叠太狠，在削波 | 软件增益调回 1.5× 左右；先听一段录音确认有没有破音 |
| 只录到旁边同学说话，老师很远 | 麦克风朝向错了 / 坐在走道边 | 把麦克风那一侧转向音箱；往中间挪两个位置 |
| 老师走动时声音忽有忽无 | 老师的手持麦离嘴时远时近，或无线麦串频 | 这是源头问题，你改不了；依赖课后 Whisper 重新转写把碎片补上；下次优先找官方录播 |
| 转写跑到一半卡住 / 风扇狂转 | 模型太大、内存不够、没插电降频 | 插电；换成 small；关掉其他大程序；分两次转写 |
| 转写完发现少了后半节课 | 中途休眠了 / 硬盘满了 | 插电并禁止休眠；上课前确认剩余空间；下次中途瞄一眼计时器 |
| 专业术语、人名一直错 | 模型没见过这些词 | 在笔记里把关键术语写下来，课后让 AI 概要时一并参考；术语固定错法可以整段替换 |
| 云端转写报错 / 401 | Key 没填对、Base URL 写错、余额用完 | 去设置里检查服务商、Base URL、Key；先在小段音频上试一次再跑整节课 |

## 七、关于录课这件事

最后一点小提醒，一句话的事：

大多数学校对课堂录音是默认允许个人学习使用的，但也有一些老师或院系有自己的规定（尤其是涉及讨论课、案例、未发表内容的课）。**第一次课后找老师说一句"我是留学生，英语跟不上，想录下来课后复习，可以吗"，基本上不会被拒绝**，而且老师知道之后，很多还会顺手把课件或官方录播链接发给你。

录下来的内容**只给自己用就好**——不要上传到网盘公开分享、不要卖笔记、不要发到群里传播。这既是规矩，也是对愿意让你录的老师的回报。

祝上课顺利。
