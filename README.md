## 一、怎么打开

### 方式 A：桌面软件（推荐，已经打包好了）

**安装包就在桌面上：`VoiceCollector-1.0.0-arm64.dmg`**

1. 双击这个 dmg
2. 把出现的 **VoiceCollector 图标拖到「应用程序」文件夹**
3. 去启动台打开它

装好之后：**不需要源代码、不需要 Python/Node、不需要终端、不需要联网、不需要 API Key。**
AI 模型（667 MB：三档 Whisper + 翻译模型）已经打包在 App 里面了。

> 发给同学用：AirDrop 或网盘传这个 dmg 就行。
> 对方第一次打开会提示「无法验证开发者」——**右键点 App → 选「打开」→ 再点「打开」**，一次就好。
> （因为这个 App 没有花钱买苹果的开发者签名，不是有问题。）

重新打包（改了代码之后）：

```bash
cd desktop && npm install && npm run dist:mac
```

> 第一次打开如果提示「无法验证开发者」：右键点 App → 选「打开」→ 再点「打开」。只需要做一次。

### 方式 B：网页版（不想装东西就用这个）

双击 **`启动.command`**（Windows 是 `启动.bat`），会自动开一个小服务器并打开 Chrome。

> ⚠️ 不要直接双击 `web/index.html`——浏览器在 `file://` 下不给用麦克风。网页会直接拦住你。

在 Chrome 里打开后，点地址栏右侧的安装图标（⊕）可以把它装成桌面 App。

**桌面版和网页版的区别**：网页版可以用 Chrome 的实时语音识别（字幕零延迟，近距离很好用）；
桌面版没有这个（Electron 里没有 Google 的语音服务），但有完整的本地 Whisper，远距离更准。

## 二、上课流程

### 上课前（30 秒）

1. 选 **老师**、**学科**（第一次点右边的 `＋` 新增）
2. 选 **识别引擎**（见下一节），大教室选「双引擎」或「本地 Whisper」
3. 点 **「麦克风试音（10 秒）」**，说几句话——它会告诉你音量够不够、能不能识别到
4. 点 **🎙 开始录制**

### 上课中

- 左边实时出现老师的原话，下面绿色是中文翻译
- 右上角有计时器和实时音量条（音量条在动 = 正在听到声音）
- 听到重点点 **⭐**，想写东西点 **📝**，都会进最后的文档
- **超过 90 秒没识别到任何文字会弹红色警告**，提醒你检查麦克风
- Chrome 的识别引擎每隔几分钟会自己断线，程序会自动重连，还有 25 秒看门狗防假死

### 下课

点 **⏹ 结束并生成文档**，自动完成：保存录音 → 补翻译 → 生成中文课堂概要 → 存进资料库。

### 🏆 课后精修（双模型）

课程页第一个按钮。它会一条龙做完：

1. **重新识别** —— 用更准的 whisper-small 把整段录音重跑一遍（比上课时的实时识别准）
2. **重新翻译** —— opus-mt + 1020 条术语表
3. **逐句对比取优** —— 把新译文和**上课时那一版旧译文**逐句打分比较，各取最好的一条

第 3 步是真的双候选：重新识别之后**原文本身都可能不一样**，不是自己跟自己比。
落选的那版会保留，点一下中文就能切换查看。

### 关于「本地大模型」（默认关闭，建议别开）

原本的设计是让 opus-mt 和一个本地 Qwen 各翻一遍再取优。**实测证明这条路在浏览器里走不通**：

| 组合 | 结果 |
|---|---|
| Qwen 1.5B + WebGPU | 数值崩溃，输出 `"最高!!!!!!!!!..."` 纯噪声 |
| Qwen 1.5B + CPU(WASM) | 内存不足 `std::bad_alloc` |
| Qwen 0.5B + CPU(WASM) | 能跑，但**会编造内容** |
| 同样的模型 + node 命令行 | 正常（1.33 秒/句）——所以是浏览器端后端的问题 |

0.5B 的真实输出：

```
✅ 最高法院（Supreme Court）判定…受《第一修正案》保护的
❌ "changing nature of privacy in the digital age"
   → "这是一个好问题，但它需要时间来回答"        ← 整句编造
❌ "due next Friday before midnight"
   → "明天凌晨四点完成"                          ← 截止时间编错
```

三条全部被择优器拦下（0 胜 3 负），所以从安装包里移除了，设置里保留开关。
真正值得的第二个模型是**云端 AI**（配了 API Key 之后自动启用）。

---

原始的模型性格对比数据（说明择优规则为什么那样设计）：

| 原文 | opus-mt | 本地大模型 |
|---|---|---|
| The Supreme Court ruled that the **First Amendment** protects... | 第一修正案保护这种言论 ✅ | 受**宪法**保障 ❌ 术语被简化 |
| we're not going to read that if it's a lot **but that is something that leads into...** | 我们不会读，如果它很多 ❌ **后半句丢了** | 整句都译出来了 ✅ |
| due next Friday **before midnight** | 下星期五**午夜前** ✅ | 下周五**凌晨** ❌ 时间译错了 |

所以评分里**数字和日期保真权重最高**——作业和考试时间错了危害最大。
落选的那版会保留，讲稿里点一下中文就能切换查看，段落上有 `MT` / `AI` 小标签标明谁胜出。

设置里可以打开「每节课结束后自动精修」（很慢，建议插电时再开）。

### 📦 在桌面版和浏览器之间搬运

桌面 App 和 Chrome 是两个完全独立的数据库，用 App 录的课在浏览器里看不到。
所以有**课程包**：课程页点 **「📦 整节课打包（含录音）」** 导出一个 `.vcpack` 文件，
到另一边资料库点 **「📥 导入课程包」** 就能完整恢复——**包括原始录音**，
所以到了浏览器那边照样能重新识别、重新翻译、打包给 AI 讲解。

老师和学科会按名字自动合并，不会重复建；id 撞车会自动改名，不会覆盖本机已有的课。
实测往返是**字节级一致**的。

### 🎧 原声回放：适应语速的核心功能

打开任意一节课的「完整讲稿」，每句话左边有三个按钮：

| 按钮 | 作用 |
|---|---|
| ▶ | 播放**这一句**的原声 |
| 🔂 | 这一句连放 3 遍（跟读用） |
| 🎤 | **跟读练习**：先听原声，再录你自己说一遍，对比用时 |

顶上有播放条：**0.5× / 0.75× / 1× / 1.25× / 1.5× 变速**（变速不变调）、上一句/下一句、
**字幕跟读滚动**（播到哪句哪句高亮并自动滚进视野）。

键盘：**空格**播放/暂停，**←→**切上下句。

> 为什么这个最重要：适应英语课堂语速，唯一有效的练习是**反复听真实语速的原声**。
> 读一百遍讲稿也不会让耳朵变快。

**跟读练习**会告诉你「原声 3.2 秒，你用了 5.1 秒，慢了 59%」——
这个数字本身就是最直接的进步指标。慢太多会建议你先降到 0.75× 跟熟再回原速。

### ☁️ 自动备份到你的云盘

课程仍然存在本机（快、能搜、离线可用），但每节课结束后会**自动写一份完整备份**

**不需要注册账号、不需要 API Key**，用的是你已有的云盘，云盘自己负责同步。
电脑坏了或换设备，在新机器上「导入课程包」就全回来了。

> 内容没变的课不会重复写（云盘同步很贵），所以可以放心开着自动备份。

## 三、识别引擎怎么选

**默认就是「双引擎」，不用改。**

| 引擎 | 延迟 | 准确率 | 需要联网 | 适用 |
|---|---|---|---|---|
| 浏览器实时识别 | 几乎没有 | 近距离好，远了明显变差 | 要 | 小教室、坐前排 |
| 本地 Whisper | 20 多秒一段 | 远距离、噪声强得多 | **不要** | 大教室、扩音器 |
| **双引擎（默认）** | 实时字幕 + 最终稿校正 | 最稳 | 只有实时字幕那部分要 | **推荐** |
| 云端 Whisper | 20 多秒一段 | 最高 | 要，且要 Key | 你愿意花钱时 |

「双引擎」的逻辑：浏览器负责出实时字幕让你上课跟得上，本地 Whisper 在后台安静地跑，
**下课时自动比较两份稿子，用更完整的那份做最终稿**，另一份完整保留做参考——两边都不会丢。

如果浏览器识别中途挂了（没网、权限被撤、引擎抽风），Whisper 会顶上，录音照常不停。
反过来如果 Whisper 加载失败，浏览器识别也还在跑。**两条腿走路，断一条还能继续。**

Whisper 模型有三档，在设置里选：

| 模型 | 体积 | 是否内置 | 说明 |
|---|---|---|---|
| 基础版 whisper-base | 142 MB | ✅ 已打包 | 普通教室、坐前排。加载 1.4 秒 |
| **标准版 whisper-small** | 288 MB | ✅ 已打包 | **大阶梯教室 + 扩音器的推荐档** |
| 最准 large-v3-turbo | 537 MB | ❌ 需联网下 | 口音特别重、术语特别多时再考虑 |

> ✅ 前两个模型**已经打包在软件里**，开箱即用，断网也能跑。
> 只有第三个需要联网下载——不建议在教室里才下。

**实测性能**（M 系列芯片 + WebGPU）：模型 1.4 秒加载完，64 秒的课堂音频 2 秒识别完（约 32 倍实时）。
也就是说一节 90 分钟的课，GPU 实际只工作 3 分钟左右，比想象中省电得多。

## 四、⚠️ 最重要的两件事

### 1. 把麦克风设成系统默认输入设备

浏览器的实时识别只认**系统默认输入设备**（这是 API 限制，改不了）。
上课前请到 *系统设置 → 声音 → 输入*，把你要用的麦克风设为默认。

（本地 Whisper 没有这个限制，它用的是应用里选的那个麦克风。）

### 2. 大教室一定要开「大教室模式」

设置页 → 远距离/大教室 → 打开 **大教室模式**。它会一次性做这些事：

- 启用针对「PA 扩音 + 混响」调过参的音频链（高通去空调低频 → 削中低频浑浊 → 抬人声清晰度 → 压缩把远处声音提起来 → 限幅防削波）
- 软件增益提到 3×
- 打开自动增益
- 开始保存分段音频，供课后整段重新转写

**详细的座位、麦克风、摆放建议见 [docs/远距离录音指南.md](docs/远距离录音指南.md)** —— 
50 米 + 扩音器这个场景我专门写了一份指南，包含为什么"距离不是主要矛盾"、该坐哪、买什么、故障排查表。

## 五、完全不用 API Key 也能用

这是设计的底线：**不填任何 Key、断网的情况下，录音 → 识别 → 翻中文 → 生成中文笔记，整条链路必须完整。**

| 环节 | 首选（免费离线，已内置） | 其次 | 兜底 |
|---|---|---|---|
| 语音识别 | 本地 Whisper（已打包） | 浏览器实时识别 | 云端 Whisper（要 Key） |
| 翻译 | 本地 OPUS-MT 模型（已打包） | Chrome 内置翻译 | 云端 AI（要 Key） |
| 课堂概要 | 本地结构化分析 | 本地小 AI（可选，要下 500MB+） | 云端 AI（要 Key） |

**离线的课堂概要到底能做到什么程度？** 它会自动抽出：
主题分段、老师下过的定义、说了 "remember / this will be on the exam / write this down" 的考点句、
作业与 deadline（含"下周五""午夜前"这类时间）、枚举步骤、公式、术语表、课堂问答、
以及"这里可能听错了"的存疑片段——全部带时间戳，并附中文翻译。这不是关键词堆砌，是可以直接拿来复习的。

### 还有一招：把课打包丢给任何 AI

课程页里的 **「🤖 打包给 AI 学习」** 会把这节课整理成一份写好指令的提示词，
你复制粘贴到 **Claude / ChatGPT / Kimi / DeepSeek 的免费网页版**，它就会当你的助教。
可以选「帮我复习 / 给我出题 / 逐点讲懂 / 帮我押考点 / 翻译润色」五种模式，内容太长会自动分段。
这是不花钱拿到高质量辅导最实际的办法。

如果你**愿意**配 Key，概要质量会明显更好（会真正读懂内容，而不是抽取关键句）。
设置页支持 Anthropic (Claude) 和任何 OpenAI 兼容接口（DeepSeek / Kimi / 智谱 / 本地 Ollama），
Key 只存在你这台电脑的浏览器里。

**模型文件预下载**（可选，让软件彻底离线）：

```bash
node scripts/fetch-models.mjs --list          # 看有哪些模型
node scripts/fetch-models.mjs --all           # 全部下载
node scripts/fetch-models.mjs --all --mirror hf-mirror.com   # 走国内镜像
```

## 六、省电

一节课 1.5 小时，笔记本很可能没插电，所以做了这些：

- 音量条从 60fps 降到 8fps，页面切到后台完全停掉
- 实时讲稿视图只保留最近 120 条 DOM 节点（完整内容仍在数据库里，导出不受影响）
- 自动保存从 1.5 秒拉长到 4 秒，关键动作（标记、笔记、暂停）立刻落盘
- 页面在后台时暂停翻译排队，回到前台再补（**录音和识别永远不停**）
- 录音码率降到 32kbps（语音足够），磁盘写入减半
- Whisper 的 wasm 线程数默认砍到一半核心
- 静音段跳过推理（VAD），不浪费算力在空白上

**翻译改成了攒批处理**：本地翻译模型每调用一次就要唤醒一次 CPU，
逐句翻等于一节课几百次唤醒，CPU 始终进不了深度睡眠。现在攒 8 秒一批（省电模式 20 秒），
唤醒次数降一个数量级，译文质量反而更好（有上下文）。

**省电模式**（设置页）：只跑浏览器识别、翻译 20 秒一批、音量表降到 2fps、不阻止屏幕休眠。
代价是没有 Whisper 校正，远距离准确率会降——**大教室别开，宁可插电**。

实测参考：双引擎跑满 90 分钟，M 系列笔记本大概掉 25–40% 电量。
如果你觉得发热异常，**先用「活动监视器」看看是不是别的进程在跑满 CPU**——
系统的蓝牙服务、通讯录同步这类进程卡死时会各占一整个核心，比这个软件费电得多。

## 八、常见问题

**一直不出字？**
→ 先点「麦克风试音」。音量条不动 = 系统选错输入设备了。
→ 地址栏左边的图标点开，确认麦克风是「允许」。

**中途不小心关了？**
→ 每 4 秒自动存一次，重新打开会自动恢复，去资料库点「重新生成概要」即可。

**远距离识别还是不准？**
→ 去那节课点 **「☁︎ 用云端重新转写整节课」**，用完整录音重跑一遍（需要开过「保存分段音频」）。
→ 看 [docs/远距离录音指南.md](docs/远距离录音指南.md)，里面有座位和硬件建议。

**Safari 能用吗？**
→ 不能，Safari 不支持实时语音识别。用 Chrome、Edge，或者直接用桌面版。
